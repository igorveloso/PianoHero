# 🎹 Piano Hero — Documentação do Produto

> O melhor professor de piano do Brasil, com a interface de um jogo.

---

## Sobre o Projeto

Piano Hero é um app mobile de aprendizado de piano que combina a precisão pedagógica de um professor experiente com a compulsividade de design dos melhores jogos modernos. Construído para Igor Veloso aprender piano do zero ao avançado, sem teto de progressão.

**Hardware alvo:** Roland GO-88PX (Bluetooth MIDI 5.0)  
**Plataforma:** iOS e Android (React Native + Expo)  
**Filosofia:** Conteúdo curado por humanos. IA como diagnóstico. Design como produto.
